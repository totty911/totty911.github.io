12 Coding agents tools

Coding agents read a codebase, edit files, run commands, and open pull requests. Some live in an editor, some in the terminal, and some build whole apps from a prompt.

What to look for

  • Editor, terminal, or browser-based
  • Can it run tests and iterate on failures
  • Repo and secret access controls
