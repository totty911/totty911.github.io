17 Agent platforms tools

No-code and low-code agent platforms let you connect an LLM to apps, data, and triggers without writing a full application. Open-source options can be self-hosted.

What to look for

  • Self-hosting vs. cloud only
  • Number and depth of app integrations
  • Human-in-the-loop approval steps
